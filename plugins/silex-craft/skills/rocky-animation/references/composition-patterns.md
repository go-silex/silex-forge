# Composition patterns & originality rules

## Base structure types

Pick ONE structure, don't mix too many.

### Workflow
For: input → process → output, content production, AI workflows, automation chains.
Draw: input on the left, Rocky guiding or working in the middle, output on the right, soft peach arrows for the main flow.

### System fragment
For: information sources, filters, databases, renderers, an agent system's local part.
Draw: only 3-5 core modules, Rocky handling one key action.

### Before / after
For: messy/ordered, manual/automatic, scattered/converged, anxious/stable.
Draw: chaos left, calm right, orange arrow between. The character can be more exaggerated.

### Role state
For: user pain, creator state, too many tools, info anxiety, stuck→running.
Draw: 2-4 small states, one short label each.

### Concept metaphor
For: content factory, info warehouse, mental black box, workflow machine, auto-report.
Draw: one big weird object or machine, few inputs, one output. Make it memorable.

### Method layers
For: frameworks, system levels, capability stacks, content-system layers.
Draw: stacked boxes (not a formal pyramid); Rocky hauling bricks or building on the side.

### Map / route
For: idea→launch, user path, content handoff path, learning path.
Draw: one curved path, few nodes, Rocky leading a line or walking.

### Mini comic frames
For: failure→success, the real process, a gripe, before/after using.
Draw: 2-4 small scenes, one action per frame.

## How to invent an original metaphor

Reinvent the metaphor from the current article every time. Never reuse an old composition.

### Three steps
1. Turn the abstract concept into a physical action: stuck, leaking, getting heavier, sorting, settling, fermenting, opening, folding, unpacking, flowing back.
2. Turn the system structure into a low-tech object: broken machine, cardboard box, drawer, pipe, mailbox, weird dial, scale, well, ladder, strange workstation.
3. Make Rocky carry the action: not standing beside it, but stuck in the machine, pulling the wrong line, guarding a gate, hauling, patching, weighing, holding a ladder, recording, stuffing something into a weird device.

### Object pool
Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, ball of string, gate, turntable, black box, hole punch, pasta press, clothesline, weird workstation. Use only 1-2, don't pile them up.

### Rocky action pool
Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, unpack, label, recycle. The action must serve the core idea, not be weird for weirdness' sake.

## Anti-copy rule

Don't replicate the exact composition of the `assets/templates/` images. Those images calibrate Rocky's look, the pastel palette, the soft painterly style, and the dreamy mood, NOT the specific scene.

Unless the user explicitly says "copy this one / replicate this composition", invent a fresh scene for each idea: a new object, a new action for Rocky, a new layout. Reuse the character and the style, never the staging.

Same theme → still invent a new metaphor. E.g. "handoff path" doesn't have to be a row of cards; it can be Rocky passing a glowing orb across two cloud islands. "One input, many outputs" doesn't have to be arrows; it can be Rocky watering one seed that sprouts several floating shapes.
